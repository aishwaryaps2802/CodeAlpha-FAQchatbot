# FAQ Chatbot — Intelligent Question Answering System

A smart FAQ chatbot built with Python and Flask that understands 
user questions and returns the most relevant answer using NLP 
techniques like TF-IDF and cosine similarity.

## What It Does
This chatbot takes a user question, processes it using natural 
language processing, and finds the closest matching FAQ from a 
pre-defined dataset. It does not just match keywords — it 
understands the meaning of the question using mathematical 
similarity scoring.

## Features
- Natural language question matching
- TF-IDF vectorization with cosine similarity
- Text preprocessing using NLTK
- Clean chat UI built with HTML, CSS and JavaScript
- Flask backend connecting Python logic to the browser
- Easy to extend by adding more FAQs to faqs.json

## Tech Stack
- Python 3
- Flask
- NLTK
- Scikit-learn
- HTML5, CSS3, Vanilla JavaScript
